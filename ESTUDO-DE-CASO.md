# Versão pública de estudo

Cópia sanitizada da interface da Penrose, não o repositório oficial. A versão demonstra catálogo, cliente, carrinho, checkout e ERP, usando uma API e uma base locais configuradas pelo avaliador.

Foram preservados 95 commits da linha de desenvolvimento, incluindo as alterações do funil demonstrativo e do kanban. Não houve condensação em um commit único. Datas, autoria nominal e evolução foram mantidas; os identificadores mudaram após a remoção de conteúdo privado e e-mails não públicos de contribuidores.

Uma chave antiga de integração foi retirada de todas as versões em que aparecia, junto de configurações, endpoints operacionais e arquivos locais. A verificação de segredos cobriu todo o histórico a publicar, sem achados nas regras utilizadas. Não é uma garantia de ausência de vulnerabilidades.

O fluxo foi demonstrado com pedido fictício e aprovação administrativa, sem cobrança, emissão de etiqueta ou envio real. A produção percorre A fazer → Impressão 3D → Acabamento → Pronto para envio, sem alterar a situação financeira do pedido nem confirmar despacho.

Marcas e imagens pertencem aos respectivos titulares. O código é disponibilizado para leitura, execução local e avaliação; isso não concede licença comercial sobre os materiais visuais. Não use versões históricas como uma configuração pronta de produção.
